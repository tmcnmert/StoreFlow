# 🏪 StoreFlow | Entity Framework Core Training Project

This project was developed to explore the full potential of Entity Framework Core through real-world scenarios. It includes practical implementations of 60+ LINQ and EF Core methods. The project works with entities such as customers, products, categories, and orders, building and managing relational database structures.

## 🎯 Project Goal

To learn advanced data management techniques with Entity Framework Core, apply LINQ queries at a professional level, and produce efficient and readable code.

## 🧱 Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- LINQ
- Code First Approach

## 🔍 Key Features

- 🔄 CRUD Operations (Add, Remove, Update, Find)
- 🔗 Navigation Properties & Include Usage
- 📦 Eager, Lazy, and Explicit Loading
- 📊 Dashboard & Graphical Reporting
- 🧠 Advanced Data Querying with LINQ Methods
- 🗂️ 60+ LINQ & EF Core Methods with Real-World Scenarios

## 🧪 Some Methods Covered

- `Add`, `AddAsync`, `AddRange`, `AddRangeAsync`
- `Find`, `FindAsync`, `FirstOrDefault`, `SingleOrDefault`
- `Where`, `Include`, `Select`, `SelectMany`
- `Any`, `All`, `Count`, `LongCount`
- `OrderBy`, `OrderByDescending`, `ThenBy`
- `GroupBy`, `Join`, `GroupJoin`
- `Take`, `Skip`, `TakeLast`, `SkipLast`
- `Aggregate`, `Append`, `Prepend`, `Chunk`
- `Union`, `UnionBy`, `Intersect`, `Except`, `ExceptBy`
- `AsNoTracking`, `Attach`, `Entry`
